Problem- Devices on home or mobile networks use private IP addresses behind a router NAT, making them invisible to external peers on the publci Internet 

STUN functiinality- 
Peer- A queries a lightwt STUN server on the publci internet asking who am i 

The STUN server inspects incoming UDP packets and replies with Peer A's public IP and external NAT port 

Limitation- STUN works for standard NAT types but fails if a router uses symmetric NAT(requiring a relay server like TURN)


Slide 6- 

How Symmetric NAT operates 

It maps an internal private IP/port to a unique different public port for every distinct destination IP/port contacted 

When a client talks to Server 1, NAT assigns public port X. When the cliennt attempts to talk to Server 2, the router assigns a completely diff public port y

Why STUN fails with Symmetric NAT

The publci port discovered via the STUN server cannot be reused by peer B to send packets back 
The router strictyl drops incoming packets from any IP/port that the internal client has not previously sent outbound traffic to directly

This behavious necessilates fallbackl to a TURN server to realy all traffic
